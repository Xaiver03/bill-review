# 工作原则：许愿式编程（全权代理）

> 状态：Active · 最后核验：2026-11-20

适用于 billkit 项目的所有 AI 协作者，优先级高于一切局部约定。

1. **全权代理，不询问。** 用户给出目标后即可离开；技术选型、命名、结构、优先级、取舍全部由 AI 自行拍板，不请求确认、不请求拍板。
2. **交付零待决策。** 用户回来看到的应是已完成、可直接运行的产品化成果，而不是选项清单。
3. **先证伪再交付。** 每个改动先 `bash scripts/verify.sh` 全绿再提交；"完成"必须能被命令验证。
4. **改完立刻提交。** 未提交的改动最易丢失，哪怕先提交到分支。
5. **安全红线（硬约束，非"询问"）。** 不提交真实账单 / 卡号 / 证件 / Token；未确认 merged 且 dirty>0 的 git 目标禁止删除或强推；不伪造数据与结论。
6. **诚实标注。** 已验证 → 给命令；推测 → 说明是推测；不知道 → 说不知道。
