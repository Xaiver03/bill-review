# 分类设计

> 状态：Active · 最后核验：2026-11-20 · 权威实现：`src/billkit.py`

## 四级分类（按顺序，命中即止）
1. **type 优先**：`income`→收入；`neutral`→转账/理财。
2. **交易类型精确映射** `PRECISE`：餐饮美食→餐饮、交通出行→交通出行、日用百货→购物日用…（conf 0.95）
3. **退款**：含"退款"的按商户关键词归类，子类=退款（conf 0.8）
4. **通用池**（商户消费/生活服务/空/扫二维码付款等）：
   - **商户关键词规则** `KW`（conf 0.7）
   - **同商户先验**（该商户历史精确类的主导用途，conf 0.6）
   - 否则 → `其他/待分类`（conf 0.2，进复核）

## 输出契约
`purpose_l1 / purpose_l2 / confidence / classify_by / needs_review / account`。
`needs_review=1` 当 `classify_by=none` 或 `confidence<0.6`。

## 用途分类表（L1）
餐饮 交通出行 购物日用 居住 生活服务 娱乐休闲 医疗健康 教育学习 旅游住宿 人情往来 金融保险 投资理财 转账还款 收入 退款/冲正 其他

## 实测（6,533 条真实数据）
自动 81.8%（5,343）/ 待复核 18.2%（1,190）。规则与词表在 `src/billkit.py` 顶部，可直接扩充。
